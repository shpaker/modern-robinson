# Прототип ремейка «Новый Робинзон»

Играбельный прототип на Python + pygame поверх вскрытых ресурсов оригинала.
Демонстрирует, что движок целиком управляется данными игры: сцены, графика,
палитры, звук и логика читаются напрямую с оригинального диска.

## Что работает

- **Рендер сцен** из родных ресурсов: фон `SCENA*.NGB` + палитра `.COL`.
- **Все три формата графики** `NGB` (сплошной битмап и RLE-спрайт) → RGBA.
- **Персонаж Робинзон** (idle-анимация из `Roby1.mv`), тень, поворот по движению.
- **Изометрическая сетка**: клик → путь (BFS) с учётом `closed_vert` → ходьба.
- **Кликабельные объекты** (`ActiveZone` из `.OB`) с реакцией.
- **Переходы между сценами**: клик по краю/`goleft`/`gorght` → `GoScene`
  (SCENA0 ⇄ SCENA1/SCENA3 и далее по всему острову).
- **Звук шагов** из банка `WAVE.DAN` (если в pygame собран модуль mixer).

## Запуск

```bash
# из корня репозитория
.venv/bin/python remake/play.py            # интерактив (окно), сцена SCENA0
.venv/bin/python remake/play.py SCENA3     # другая сцена
.venv/bin/python remake/play.py --verify   # headless: PNG + walk.gif в /tmp/robigame
```

Управление: левый клик — идти в точку; клик по объекту — осмотреть; клик у
левого/правого края или по стрелке-объекту — перейти в соседнюю локацию; ESC — выход.

Зависимости (уже в `../.venv`): `pygame`, `numpy`, `pillow`.

## Структура

```
remake/
  engine/
    ngi.py         # NL-контейнер + расшифровка директории + кодеки
    lzhuf.py       # LZHUF (метод 0x80) — register-faithful порт из NGI32.DLL
    ngb.py         # декодер графики NGB (оба подтипа) -> indexed + RGBA
    resources.py   # индекс всех ресурсов (сцены, ролики, звук)
    scripts.py     # парсеры .SCN / .OB / .FS / .CHR
    grid.py        # изосетка: экран<->клетка, BFS-поиск пути
  play.py          # игровой цикл (pygame) + headless-верификация
  render_scene.py  # headless-композитор сцены в PNG (диагностика)
```

Кодеки (`engine/ngi.py`, `lzhuf.py`, `ngb.py`) — копии из `../tools`, приведённые
к пакетным импортам. Спецификация форматов — в [`../docs`](../docs).

## Известные упрощения (следующие шаги)

- Ходьба анимируется idle-роликом; направленная анимация `rg_XY` (8 сторон) — TODO.
- Тексты объектов показываются как `text #N` — нужна таблица строк игры.
- Позиционирование дальних клеток (`gy≥3`) неточное: изо-базис снят эмпирически,
  для пиксельной точности нужна формула из `ROBY.EXE`.
- Анимированные объекты сцены (огонь/дым/волны) пока не накладываются.
- Полный интерпретатор команд `.FS` (`If/Set/AddItem/CreateObject`) — частично
  (реализован `GoScene`); остальное — следующий этап.
