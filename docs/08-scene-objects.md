# Объекты сцены: рендер, Z-order, клик-зоны, курсоры

По кросс-проверке SCENA0..8. Глобальные константы всех сцен: `GridSize=(144,36)`,
`GridShift=(46,-99)`, `ZPerGrid=8`; варьируется только `LeftTopGrid`.

## Спрайты объектов — полноэкранные «декали»

Каждый кадр `.NGB` объекта имеет холст во весь экран (640×480; у `wave` —
1024×768) с `x0=y0=0`, а непрозрачные пиксели **уже стоят на финальных
экранных координатах**. Рендер: блит в `(NGB.x0, NGB.y0)` = (0,0). Пересчёт по
`gx,gy` НЕ нужен.

`gx,gy` объекта — **логический тег**, не позиция спрайта: задаёт Z-слой,
проходимость (`ClosedVert`) и целевую клетку подхода персонажа.

Каждый ролик несёт свою палитру `.COL`; кадр `Frame k` → k-й `.NGB` ролика.

## Экран

Дисплей 640×480: сцена в верхних 640×400 (шире → горизонтальный скролл, SCENA0
= 1024×400), панель инвентаря внизу `y=400..480` (`BAR.BAR: BarLTWH 0,400,640,80`).

## Z-order

```
z = gy * ZPerGrid + ZCoord        (ZPerGrid=8; рисовать по возрастанию z)
```

`ZCoord ∈ [0,8)` — подслот внутри ряда `gy`. Персонаж без `ZCoord` в `.CHR`;
его z = `gy_char*8 + Zc`. В SCENA0 ходибельны `gy≤2`, реквизит на `gy=3`
(z≥29) → пальма/костёр/камни/краб/прибой всегда перед персонажем. Для ремейка:
сортировать всё рисуемое по `gy*8+ZCoord`, персонажу дать `ZCoord` (напр. 7).

## Клик-зона (ActiveZone)

```
rect.xy = ActiveZone.xy + Shift - GridShift      (GridShift=(46,-99) => -GridShift=(-46,+99))
rect.wh = ActiveZone.wh
```

`Shift` — origin/hotspot объекта из его FonScript (`.FS`). Проверено на SCENA0..2,
совпадение 0–8 px. У высоких объектов (пальма, деревья) `ActiveZone` намеренно
накрывает кликабельную часть (ствол), а не весь спрайт.

## Классы анимации

- **Статичные** (1 кадр): bgstone, coco, palma, sstone, woods, clay, sound.
- **Зациклённые** (последний кадр без терминальной команды → возврат к кадру 0):
  fire (3 к.), crb (4 к.), wave (5 к.), sound (переигрывает звук по таймеру).
- **One-shot** (последний кадр содержит `DelObject`/`GoScene`/`ShowChar`): smoke
  (35 к., самоудаляется), fraskcon, rotalk — скриптовые события.

Правило: если последний кадр FonScript не содержит терминальной команды —
зациклить; иначе проиграть один раз. `Delay` брать по модулю.

## Курсоры

Значения `Cursor` в `.OB`: 0..4 — навигационные, индекс в списке `BAR.BAR`
(`hand, adv1..adv4`). Графика — `RT_CURSOR` в `ROBY.EXE`, все 32×32:

| Cursor | Вид | Назначение |
|--:|---|---|
| 0 | рука | действие/осмотр по умолчанию |
| 1 | ◄ | выход влево (`goleft`) |
| 2 | ► | выход вправо (`gorght`) |
| 3 | ▲ | вход/вглубь |
| 4 | ▼ | выход вниз |

Плюс 33 курсора «предмет-в-руке» (по выбранному предмету инвентаря; список
`Items` в `BAR.BAR`). В контейнерах данных курсоров нет — только в `ROBY.EXE`.
