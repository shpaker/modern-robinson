# Дорожная карта ремейка

Стек выбран и реализован: **Go + Ebitengine**, движок в корне репозитория.
Главный вывод реверса подтвердился на практике: весь геймплей — это данные, а
`ROBY.EXE` — интерпретатор текстовых скриптов. Эмулировать x86 не нужно, нужен
новый интерпретатор тех же ресурсов.

## Что сделано

| Слой | Состояние |
|---|---|
| Контейнер `NL`, шифр директории, все 4 кодека | 100 % записей распаковывается |
| Графика `NGB` (оба подтипа), палитры `COL` (BGR) | рендерится |
| Сцены: `.SCN`, изосетка, поиск пути, Z-порядок | 37 сцен грузятся и рисуются |
| Объекты: `.OB`, `FonScript`, хотспоты, курсоры | работает |
| Начальное состояние мира из `BEGIN.BGI` | работает |
| Интерпретатор `.FS`: `If`, переменные, инвентарь, `CreateObject`/`DelObject`, `GoScene`, `SetVert` | работает |
| Персонажи: авторские циклы ходьбы, простои, `SetRest`, Пятница | работает |
| Тексты `TEXT.DAT`, озвучка, панель инвентаря | работает |
| Окно 640×480 со скроллом, фейды `.FAD`, музыка | работает |
| Экраны: логотип, титул, опции, 12 слотов сохранения | работает |
| Мини-игры | 2 из 6 (переводчик, орган) |

## Что осталось

1. **Мини-игры 0–3** (пазлы карты и хижины, шашки, воздушный шар). Ассеты и
   раскладки разобраны ([10-minigames.md](10-minigames.md)); не хватает правил и
   констант из `MINIGAME.DLL` — целевых позиций деталей, ИИ шашек, теста посадки.
   Пока эти игры возвращают успех, чтобы квест проходился насквозь.
2. **Полное прохождение** — пройти игру от начала до конца и вычистить места, где
   логика расходится с оригиналом.
3. **Полировка** — тайминг шага под скорость, оставшиеся UI-мелочи.
4. **Релизы** — сборки под macOS/Linux/Windows и их паковка.

WASM снят с целей: ресурсы игры весят 338 МБ (150 МБ роликов, 115 МБ звука),
их не загрузить в браузер без переписывания слоя ресурсов на асинхронную
подгрузку.

## Архитектура

```
cmd/main.go                      точка входа: найти папку игры, запустить окно
internal/app                     композиционный корень: игровой цикл, сцены, UI
internal/adapters                Ebiten: изображения, анимации, звук, шрифт
internal/use_cases               логика: сетка, пути, интерпретатор, циклы ходьбы
internal/repositories (+codec)   единственная дверь к файлам игры
internal/interfaces, types       контракты и доменные данные
```

Зависимости направлены внутрь; слой ресурсов — единственное место, читающее
диск. Подробнее — [`../ARCHITECTURE.md`](../ARCHITECTURE.md).
