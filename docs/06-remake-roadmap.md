# Дорожная карта ремейка

Стек выбран и реализован: **Go + Ebitengine**, движок в корне репозитория.
Главный вывод реверса подтвердился на практике: весь геймплей — это данные, а
`ROBY.EXE` — интерпретатор текстовых скриптов. Эмулировать x86 не нужно, нужен
новый интерпретатор тех же ресурсов.

## Чему научил ремейк

Несколько мест, где «очевидная» реализация расходится с движком, — их стоит
знать до того, как писать свой интерпретатор:

- **Кадр скрипта — не список команд по порядку.** `GoScene` завершает скрипт, а
  `StartGame` его приостанавливает: ветвление по результату мини-игры записано в
  том же кадре, но решаться должно после (docs/04).
- **Движение персонажа — это анимация.** Позиция не интерполируется: под-шаговое
  смещение зашито в холсты кадров, клетку двигает `Shift char` из кадра 0
  (docs/09).
- **`HEAD.MV` — не цикл, а таблица из 9 поз**: голова выбирается по положению
  курсора (docs/09).
- **Зацикленность скрипта — свойство места вызова, а не скрипта.** В данных
  такого признака нет; угадывание по последнему кадру ошибается в 75 % случаев.
- **Выходы из локации — обычные объекты** из `ObjectList`, с квестовым гейтом;
  придумывать их клетки нельзя (docs/08).
- **Имя скрипта действия** = персонаж + предмет в руке + объект, причём предмет и
  персонаж — разные состояния (docs/08, docs/09).

WASM снят с целей: ресурсы игры весят 338 МБ (150 МБ роликов, 115 МБ звука),
их не загрузить в браузер без переписывания слоя ресурсов на асинхронную
подгрузку.

## Архитектура

```
cmd/main.go                      точка входа: найти папку игры, запустить окно
internal/app                     композиционный корень: игровой цикл, сцены, UI
internal/adapters                Ebiten: изображения, анимации, звук, шрифт
internal/use_cases               логика: сетка, пути, интерпретатор, циклы ходьбы
internal/repositories (+codec)   единственная дверь к файлам игры
internal/interfaces, types       контракты и доменные данные
```

Зависимости направлены внутрь; слой ресурсов — единственное место, читающее
диск. Подробнее — [`../ARCHITECTURE.md`](../ARCHITECTURE.md).
