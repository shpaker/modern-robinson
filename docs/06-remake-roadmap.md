# Дорожная карта ремейка

> Итог выбора стека: **Go + Ebitengine** (движок в корне репозитория). Ниже —
> исходный анализ вариантов, оставлен как обоснование.

## Можно ли сделать нативный исполняемый файл для macOS (или WASM)?

**Да, и это вполне реалистично.** Ключевая причина: **весь геймплей — это данные,
а не машинный код**. `ROBY.EXE` — интерпретатор текстовых скриптов сцен и
покадровых анимаций. Чтобы «пройти игру на macOS», не нужно эмулировать x86 или
портировать `ROBY.EXE` — достаточно написать **новый интерпретатор** тех же
ресурсов. Все форматы, нужные для этого, уже вскрыты (99.2 % записей
распаковываются).

Что уже есть на руках:
- контейнер `NL` + расшифровка директории;
- три кодека (`raw` / `LZSS` / `LZHUF`) → графика, палитры, звук, скрипты;
- текстовые `.SCN`/`.OB`/`.FS` (полный словарь команд);
- звук — готовый PCM WAV.

Что осталось для полного рендера (не блокирует старт):
- RLE-грамматика спрайтов `NGB` (подтип B) — сейчас понятен заголовок и таблица
  строк, нужна раскодировка прогонов прозрачности;
- кодек `0x100` (0.8 % записей, редкие фоны);
- бинарный `.SCR` (точная авторская раскадровка роликов) — обходится порядком
  кадров из имён `.NGB`.

## Выбор языка/стека

| Стек | Плюсы | Минусы | Вывод |
|---|---|---|---|
| **Rust + wgpu/SDL2** | одна кодовая база → нативный macOS **и** WASM, скорость, надёжность | больше кода | **рекомендуется** для «нативно + WASM» |
| **Go + Ebiten** | очень быстрый старт, кросс-платформа, есть WASM | GC, WASM тяжелее | хороший вариант, если нужен быстрый прототип |
| **Python + pygame** | быстрее всего проверить логику | нет удобного WASM, медленно, упаковка под macOS неудобна | для прототипа/референса, не для релиза |
| **TypeScript + Canvas/WebGL** | «игра в браузере» из коробки | только web | если цель именно WASM/web |

Для цели «нативный macOS-бинарь **и** возможный WASM» оптимален **Rust**:
- рендер — `wgpu` (Metal на macOS, WebGPU в браузере) или `SDL2`/`macroquad`;
- уже написанные на Python `ngi.py`/`lzhuf.py` — готовая спецификация, портируются
  в Rust почти дословно (кодеки — чистая арифметика без зависимостей);
- WASM-сборка `wasm32-unknown-unknown` + `macroquad`/`wgpu` даёт ту же игру в
  браузере без второй кодовой базы.

> Прагматичный путь: сначала **Python + pygame** как эталонный проигрыватель одной
> сцены (быстро проверить, что интерпретатор скриптов верен и игра «идёт»), затем
> переписать проверенную логику на **Rust** для релизных таргетов macOS/WASM.

## Архитектура ремейка

```
┌─ resource layer ──────────────┐   ← уже готово (ngi.py / lzhuf.py)
│  NL-контейнер, дешифр, кодеки  │
│  NGB→bitmap, COL→palette, WAV  │
├─ data model ──────────────────┤
│  Scene(.SCN)  Object(.OB)      │   ← парсеры текстовых скриптов
│  FrameScript(.FS)  vars/items  │
├─ interpreter ─────────────────┤
│  игровой цикл, тайминги,       │   ← сердце ремейка (замена ROBY.EXE)
│  события Sound/Text/If/GoScene │
│  инвентарь, флаги квеста       │
├─ subsystems ──────────────────┤
│  path-finding по сетке (NAV32) │   ← переписать по .SCN
│  рендер спрайтов Z-order       │
│  аудио-микшер (каналы)         │
└─ platform (macOS / WASM) ──────┘   ← wgpu/SDL2 или Ebiten/pygame
```

## Пошаговый план

1. **Порт кодеков в целевой язык** (Rust): контейнер, дешифр, LZSS, LZHUF.
   Эталон — `tools/ngi.py`, `tools/lzhuf.py`; проверка — побайтовое совпадение с
   выводом Python на всём образе.
2. **Рендер `NGB`:** сначала подтип A (сплошные фоны/меню — работает сразу),
   затем разбор RLE подтипа B (спрайты) → блиттинг с прозрачностью и палитрой.
3. **Парсеры `.SCN`/`.OB`/`.FS`** в структуры данных.
4. **Интерпретатор одной сцены** (`SCENA0`): загрузка фона, объектов, ходьба по
   сетке, клики по `ActiveZone`, проигрывание `.FS` (кадры + `Sound`/`Text`).
5. **Состояние игры:** `IntVariables`/`CharVariables`/`TextVariables`, инвентарь
   (`AddItem`/`DeleteItem`), флаги, `If/EndIf`, `GoScene`.
6. **Навигация:** поиск пути по сетке с учётом `ClosedVert`/`ClosedDir`.
7. **Связка сцен** → проходимость всей игры; мини-игры (`MINIGAME.DLL`) — отдельно
   (шахматы `CHESS.DAT`, и др.) — реализуются как самостоятельные модули.
8. **Упаковка:** macOS `.app` (подпись/нотаризация) и/или WASM-сборка для web.

## Юридическая заметка

Код-ремейк движка (свой интерпретатор) — это чистая инженерия. Но **ресурсы**
(графика, звук, тексты, ролики) — собственность правообладателя (Никита). Для
личного использования/исследования это приемлемо; для публичного распространения
ремейка ассеты нельзя включать без разрешения — обычно распространяют только
движок, а игрок подкладывает свой оригинальный диск.

## Оценка объёма

- Кодеки + загрузчик ресурсов: **готово** (нужен лишь порт, ~1–2 дня на Rust).
- Рендер `NGB` (вкл. RLE): ~2–4 дня.
- Интерпретатор сцен/скриптов до «проходимой одной сцены»: ~1–2 недели.
- Полная игра (все сцены, навигация, мини-игры, полировка): месяцы, но
  инкрементально и предсказуемо — без «чёрных ящиков», т.к. всё в данных.
