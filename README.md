# Новый Робинзон

Реверс-инжиниринг и открытый ремейк квеста «Новый Робинзон» (Никита, 1999) на
**Go + Ebitengine**. Форматы игры вскрыты полностью, ремейк — новый
интерпретатор оригинальных ресурсов. Работает на macOS, Linux, Windows и в
браузере.

> Ассетов игры в репозитории нет — нужна своя копия игры.

## Как запустить

Ресурсы читаются из папки игры напрямую, конвертировать ничего не нужно.

**1. Извлечь образ в папку:**
```bash
# macOS
unar ROBINSON.iso                  # -> ROBINSON/   (или hdiutil attach ROBINSON.iso)
# Linux
7z x ROBINSON.iso -oROBINSON       # -> ROBINSON/   (или sudo mount -o loop)
```
Итог — папка (`GAME_DIR`), где есть `DATA/WAVE/WAVE.DAN`.

**2. Собрать и запустить** (Go 1.24+, [just](https://github.com/casey/just)):
```bash
just build
./robinson /path/to/GAME_DIR
```
Либо положить `robinson` прямо в `GAME_DIR` и запустить без аргументов.
Кросс-сборки: `just build-macos|build-linux|build-windows`. Браузерная версия —
[docs/11-web-build.md](docs/11-web-build.md).

## Управление

| | Мышь | Палец |
|---|---|---|
| Идти | клик по земле | тап |
| Действие с объектом | клик по объекту | тап |
| Предмет на себя | клик по герою | тап по герою |
| Название объекта | навести курсор | прижать палец |
| Прокрутить сцену | курсор у левого или правого края | вести пальцем |
| Сменить локацию | клик у края сцены, где курсор — стрелка | тап у края сцены |
| Пропустить ролик | клик или любая клавиша | тап |

Действие совершается предметом, выбранным в панели; «рука» — взять или сделать
самому. Камера сама за героем не следит: при ходьбе она едет к точке клика.

**Панель:** портрет — переключиться между Роби и Пятницей (когда Пятница в
команде), стрелки — листать предметы, предмет — выбрать, карта — быстрый
переход по острову (когда карта открыта), дискета — главное меню.

**Клавиши:** **Esc** — главное меню, **F5**/**F9** — быстрые сохранение и
загрузка. Отладка: **F1** — сетка ходьбы, клик-зоны, пути и что сделает клик;
**F2** — переменные квеста и последние команды.

**Мини-игры:** **Esc** — выйти. В пазлах хижины и карты правая кнопка (на
таче — долгое нажатие) поворачивает обрывок. Воздушный шар: **↑**/**↓** или
клик по Робинзону/Пятнице — подняться/спуститься.

## Настройки

Необязательный `config.yml` рядом с бинарником или в папке игры. Любой
пропущенный или неверный ключ игру не ломает — берётся значение по умолчанию:

```yaml
scale: 2          # увеличение окна (окно игры 640×480), 1..4
sound: 1.0        # громкость звука, 0..1
music: 0.7        # громкость музыки, 0..1
speed: 0.5        # скорость игры, 0..1 (0.5 — как в оригинале)
debug: false      # запускать с отладочным слоем (он же F1)
fullscreen: false
```

Громкость и скорость меняются и в игре — в главном меню (**Esc**).

## Какие файлы игры нужны

Бинарник читает `GAME_DIR` только на чтение; сохранения кладёт туда же
(`robinson00.sav` + миниатюра `robinson00.png`, 12 слотов).

| Путь | Что берётся |
|---|---|
| `DATA/SCEN/*.DAN` | сцены: `.SCN` (сетка, объекты, звуки), `.OB` (объекты), `.FS` (анимации и логика) |
| `DATA/SCEN/*.DAT` | фоны сцен: `.NGB` + палитра `.COL` + таблица затемнения `.FAD` |
| `DATA/MOVIE/*.MV` | ролики: спрайты персонажей, предметов, анимации объектов |
| `DATA/WAVE/WAVE.DAN` | звук и музыка игры |
| `DATA/CHAR/ROBY.DAN`, `FRID.DAN` | персонажи: `.CHR`, циклы ходьбы `RG_XY`/`FG_XY`, `DO.LST` |
| `DATA/STARTUP.DAN` | `STARTUP.INF` (список сцен, начальные переменные) и `TEXT.DAT` (все тексты) |
| `DATA/BEGIN.BGI` | начальное состояние объектов в каждой сцене |
| `DATA/BAR/BAR.DAN`, `BAR.DAT` | панель инвентаря: раскладка `BAR.BAR` и её графика |
| `DATA/OPTIONS.DAT` | главное меню (оно же экран опций), экраны сохранения и загрузки |
| `LOGO.DAT` | логотип студии, титульный экран и экран «Загрузка» |
| `CRYPT.DAT`, `PIPE.DAT`, `HOUSE.DAT`, `MAP.DAT`, `CHESS.DAT`, `BALOON.DAT` | мини-игры |
| `MINIGAME.WDT` | звуки мини-игр |

Не используются: `*.EXE`, `*.DLL` (движок и мини-игры переписаны), `DIRECTX/`,
`DOCUMENT/`, `CONFIG.DAT`, `LANG.DAT`.

## Разработка

```bash
just check          # fmt + lint + test
just demo           # headless-прогон -> PNG-кадры
just scene PALACE   # кадр конкретной сцены
```

`ROBINSON_TRACE` печатает в stderr команды скриптов, которые изменяют мир:

```bash
ROBINSON_TRACE=1 ./robinson                 # все команды
ROBINSON_TRACE=goscene,setvar ./robinson    # только переходы и флаги
```

Устройство — [ARCHITECTURE.md](ARCHITECTURE.md), форматы игры —
[docs/](docs/README.md), инструменты реверса (Python) и веб-сборки (Go) —
[tools/](tools). План — [todo.md](todo.md).

## Ассеты

Код и инструменты — собственная работа и распространяются вместе с репозиторием.

Графика, звук и тексты игры принадлежат правообладателю (Никита). В репозитории
их нет и никогда не было. Веб-версия их тоже не содержит: она скачивает набор,
который `tools/packweb` упаковывает из вашей копии игры, с хоста данных
(`?data=` — любой другой источник, включая локальный `just web-serve`), а
фавикон `just build-wasm` берёт из `START.ICO` той же копии.
