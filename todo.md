ЭТАП 0. РЕВЕРС-ИНЖИНИРИНГ ФОРМАТОВ  [x]
--------------------------------------
[x] Распаковка RAR/ISO, инвентарь ресурсов (736 контейнеров, 28k записей)
[x] Контейнер NL: заголовок, директория, layout
[x] Дешифр директории (потоковый шифр, ключ = поле @0x14)
[x] Кодек 0x00 (raw), 0x40 (LZSS), 0x80 (LZHUF — некононические таблицы)
[x] Формат NGB (оба подтипа: сплошной битмап + RLE-спрайт)
[x] Палитра COL = Windows BGR (своп R<->B)
[x] Скриптовый язык .SCN/.OB/.FS: словарь команд
[x] Устройство движка NGI (DLL, экспорты, адреса) — docs/
[ ] Кодек 0x100 (графический вариант, 0.8% записей) — sub_26C30
[ ] Формат бинарного .SCR (раскадровка роликов)
[ ] Формат сейва .SAV/.BGI (можно спроектировать свой)
