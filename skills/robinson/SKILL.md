# Новый Робинзон через MCP

Игра с флагом `-mcp` — MCP-сервер `robinson`, и Робинзоном играешь ты.
Аргумент — задача: вся игра или кусок (накормить и напоить Роби, решить
головоломку, дойти до места); задачи нет — вся игра. Если аргумент — путь,
это папка игры.

Сначала проверь, есть ли в сессии инструменты сервера: `look`, `use`, `go` и
другие, в Claude Code — `mcp__robinson__look` и т. д. (если они среди
отложенных, загрузи их поиском инструментов). Есть — раздел «Игра», нет —
«Подготовка».

## Честная игра

Всегда, и при подготовке тоже:

- Мир ты узнаёшь только из ответов игры, подсказать может только игрок. Не
  открывай, не читай и не разбирай файлы игры (ресурсы, скрипты, сохранения),
  исходники ремейка и его документацию; не ищи прохождения и подсказки в сети.
  Папку игры и архива не листай (`ls`, `find`) — проверяй только точные имена
  (`test -f`).
- Играй только инструментами `robinson`: без своих скриптов, циклов, мостов,
  прокси и обёрток вокруг игры. `robinson -mcp` сам не запускай.
- Не перебирай варианты вслепую. У каждого действия своя причина: перед
  вызовом напиши её в чат, а в `why` коротко повтори. После ответа напиши в
  чат следствие — что вышло и что ты из этого понял.

## Игра

1. Инструкции сервера главнее этого файла: в них роль Роби, что значат
   данные, правила головоломок и когда сохраняться.
2. Перед первым ходом поздоровайся, как просят инструкции, назови задачу и
   осмотрись (`look`).
3. Кусок сделан или дальше без игрока не выйдет — сохранись, скажи, что
   вышло, и жди новой просьбы.
4. Продолжить прошлую партию — спроси слот и загрузись (`load`). Твои
   сохранения — в слотах 10 и 11, слоты 0–9 — игрока.

## Подготовка

MCP-серверы подключаются при старте сессии: `.mcp.json`, записанный сейчас,
заработает только в новой. Не обходи это — не запускай сервер сам и не
подключай его к этой сессии. Твоё дело — подготовить папку игры и отправить
игрока в новую сессию в ней.

Если в текущей папке уже есть `.mcp.json` с `robinson`, значит, сервер не
одобрен или не запустился: пусть игрок откроет `/mcp`, включит `robinson` или
посмотрит ошибку (в конце); инструменты так и не появились — пусть начнёт
новую сессию. Иначе:

1. **Папка игры** — текущая, если в ней есть `DATA/WAVE/WAVE.DAN`; иначе из
   аргумента, иначе спроси; сам по диску её не ищи. Проверь только этот файл и
   что в папку можно писать (`test -f`, `test -w`). Файла нет — пусть игрок
   скопирует игру с диска в обычную папку (README, «Как запустить», шаг 1).
   Не бери папку исходников ремейка: там решения.
2. **Сборка** — по `uname -sm`:

   | Система | Бинарник |
   |---|---|
   | `Darwin arm64` | `robinson_darwin_arm64` |
   | `Linux x86_64` | `robinson_linux_amd64` |
   | Windows x64 (`MINGW64…`, `MSYS…`) | `robinson.exe` |

   Проверь это имя (`test -f`) в папке игры, потом на два уровня выше каталога
   этого скилла — там распакованный архив релиза; нет — спроси путь. Для
   других систем готовой сборки нет: скажи игроку, что собрать её он может сам
   (README, «Из исходников»); сам исходники не открывай и не собирай. macOS:
   сборки не подписаны — спроси игрока и сними карантин
   `xattr -d com.apple.quarantine <бинарник> 2>/dev/null || true` (и с
   запускалки `robinson`, если она есть), затем `chmod +x`; Linux: `chmod +x`.
3. **`.mcp.json`** в папке игры — если его там нет (есть — не трогай):
   - сборка лежит в папке игры, а на macOS и Linux рядом есть и запускалка
     `robinson` из архива, — запиши тот же файл, что в архиве:

     ```json
     {
       "mcpServers": {
         "robinson": {
           "type": "stdio",
           "command": "./robinson",
           "args": ["-mcp"]
         }
       }
     }
     ```

     Клиент запускает сервер из папки игры, и игра находит себя сама;
   - иначе — полные пути, без `~`:
     `"command": "/полный/путь/robinson_darwin_arm64"`,
     `"args": ["-mcp", "/полный/путь/к/папке/игры"]`. `-mcp` — строго до
     пути, иначе игра запустится без сервера. В Windows пути — с прямыми
     слэшами: `C:/Games/Robinson/robinson.exe` (в Git Bash такой путь даёт
     `cygpath -m`).
4. **Ручная настройка.** Если в папке игры `claude mcp get robinson`
   показывает сервер не из `.mcp.json` (область local или user — ручная
   настройка из README), он перебьёт `.mcp.json`: покажи его игроку и
   предложи `claude mcp remove robinson -s <область>`.
5. **Скажи игроку** — и на этом всё:
   - открыть новую сессию Claude Code в папке игры: `cd <папка игры> && claude`
     или новая сессия с этой папкой в приложении;
   - разрешить сервер `robinson` из `.mcp.json` (не спросило — `/mcp`,
     включить `robinson`); окно игры откроется само и закроется вместе с
     сессией;
   - сказать, что сделать: сыграть или кусок игры, если задача была.

Если в `/mcp` у `robinson` ошибка: `game resources not found` — сессия открыта
не в папке игры или неверен путь к ней; `no build for …` — для этой системы
нет сборки; macOS не открывает файл — не снят карантин; в окне логотип и меню
вместо партии — `-mcp` стоит после пути. Проверить команду в терминале — дело
игрока (README, «Если не работает»); сам её не запускай.
